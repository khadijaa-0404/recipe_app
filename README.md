
# 🍽️ Recipe App

Welcome to **Recipe App**! 👨‍🍳✨

Recipe App is a simple and interactive **Streamlit** web application that helps users organize, manage, and discover delicious recipes in one place. Whether you want to save your favorite recipes, search by ingredients, or get AI-powered cooking ideas, this app makes cooking easier and more enjoyable.

## 🌟 Features

- ➕ Add new recipes
- 🔍 Search recipes by ingredients
- 📖 View all saved recipes
- 🎲 Get a random recipe suggestion
- ⭐ Rate recipes
- 📊 Sort recipes by rating
- 🍽️ Scale ingredient quantities based on the number of servings
- 🛒 Generate a shopping list from multiple recipes

## 🤖 Smart API Features

### 🌐 Import Recipes from the Web
Search for any dish using **TheMealDB API** and instantly import it into your recipe collection.

### 👨‍🍳 Smart Chef Assistant
Powered by **OpenRouter (GPT-4.1 Mini)**, the Smart Chef can:
- 🍅 Create a recipe using the ingredients you already have.
- 🥗 Suggest ingredient substitutions based on dietary restrictions (e.g. vegan, gluten-free, low-carb).

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Requests
- OpenRouter API
- TheMealDB API
